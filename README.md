## 🔷 Sobre a certificação DP-900

**Microsoft Certified: Azure Data Fundamentals**

Demonstra conhecimento fundamental sobre conceitos centrais de dados relacionados aos serviços de dados do Microsoft Azure.

**Nível:** Iniciante
**Produto:** Azure
**Função:** Data Engineer
**Assunto:** Databases

O que cai na prova: conceitos de dados relacionais e não relacionais, cargas de trabalho transacionais e analíticas, e serviços de banco de dados do Azure (como SQL e Cosmos DB).

**Para quem é:** pessoas que estão começando a trabalhar com dados na nuvem e desejam iniciar uma carreira na área de dados, engenharia de dados ou análise. Você deve estar familiarizado(a) com os conceitos de dados relacionais e não relacionais, e com diferentes tipos de cargas de trabalho, como transacionais ou analíticas.

> 💡 A certificação DP-900 pode ser usada como preparação para outras certificações de função do Azure, como Azure Database Administrator Associate ou Azure Data Engineer Associate, mas não é pré-requisito para nenhuma delas.

## 🔷 Applied Skills - prática extra para complementar o DP-900

Diferente do AZ-900, o DP-900 não tem uma trilha oficial de "guided projects" na Microsoft Learn, é uma certificação mais conceitual. Mas a Microsoft oferece os Microsoft Applied Skills: credenciais gratuitas, baseadas em cenário, com labs reais (não simulados) no Azure/Fabric, que **validam habilidades práticas específicas**. Elas complementam muito bem os conceitos vistos nas 4 trilhas do DP-900.

💡 Applied Skills não substituem nem são pré-requisito da certificação DP-900 - são um **complemento prático opcional**, cada uma rende um badge próprio verificável.
